# Code of Conduct

ClockFence adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and welcoming, accept constructive criticism gracefully, and focus on what is best for the community. Harassment, insults and publishing others' private information are not acceptable.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@fiqahmad](https://github.com/fiqahmad), through a GitHub direct contact or by opening a [private security advisory](https://github.com/fiqahmad/clockfence-qr-attendance-geofence/security/advisories/new) marked "Code of conduct". Reports are handled confidentially.

## Enforcement

The maintainer follows the Contributor Covenant 2.1 enforcement guidelines: correction, warning, temporary ban, and permanent ban, depending on the severity and repetition of the behaviour.
